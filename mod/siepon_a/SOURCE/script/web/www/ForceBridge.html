Forced Bridge mode

This ignores the PON Classifier rules from the OLT and forces the addition of bridge settings.
When enabled, this will forcibly bridge LLID 0-15 and UNI.
If your ISP has enabled 802.1x authentication, 802.1x authentication will be forcibly bypassed.

Specifies the MAC addresses allowed upstream when Forced Bridge mode is enabled.
Generally, this value will be the Router ( HGW / CPE ) WAN MAC address.
Specifying 00:00:00:00:00:00 will allow all MAC addresses.
