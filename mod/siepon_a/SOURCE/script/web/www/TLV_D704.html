Chipset Info (D7/04)

Configure the ONU SoC Chipset Info.
The configured value will be reported to the OLT as the DPoE TLV D7/0004 value.

JTAG JDEC ID ( Hex 4 Byte. 0000 - FFFF )
JDECID :
  • CORTINA Access : 0879
  • Broadcom : 0203
  • Sumitomo Electric : 01F2

Chip Model ( Hex 4 Byte. 0000 - FFFF )
Chip Model :
  • CORTINA Access - CA8289 : 4701
  • Broadcom - BCM55030 : 4701
  • Sumitomo Electric - FTE7653R (CA8271) : 6858

Chip Version ( Hex 8 Byte. 00000000 - FFFFFFFF )
Chip Version :
  • CORTINA Access - CA8289 : 00001000
  • Broadcom - BCM55030 : B2110816
  • Sumitomo Electric - FTE7653R (CA8271) : A17C0449
